# Vendored proving keys

`30/semaphore.arkzkey` is the depth-30 Semaphore proving key in the
Arkworks-native format consumed by `semaphore-rs`. It is intentionally checked
in so builds using the `depth_30` feature do not fetch a cryptographic build
input from a third-party endpoint.
